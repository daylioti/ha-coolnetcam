Add your cameras to Home Assistant

One Generic Camera entity per stream. ← back to live grid

  1. In Home Assistant: Settings → Devices & Services → Add Integration → “Generic Camera”.
  2. Paste the Stream Source URL below. Leave Still Image URL blank.
  3. (Optional) Use the suggested name. Finish — it creates a camera.* entity.
  4. Repeat for each camera.
Tip: if you reached this page via homeassistant.local, the URLs below use that hostname. For casting to a Chromecast, reopen this page using your HA box's numeric IP (e.g. http://192.168.x.x:8090/setup) so the copied URLs use the IP — Chromecast can't resolve .local.
